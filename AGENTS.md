# DealForge engineering guidelines

- Keep code simple, readable, and maintainable.
- Organize code by responsibility.
- Keep files focused and avoid unnecessary abstractions.
- Add folder nesting only when it serves a clear purpose.
- Write tests for meaningful behavior.
- Handle errors explicitly.
- Never hardcode secrets or credentials.
- Explain why each new dependency is needed.
- Make small, focused changes.
- Explain important technical decisions in simple English.
